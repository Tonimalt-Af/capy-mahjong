# Mahjong Capybaras: audit (30 octobre 2026)

This is a read-only audit of the live site (https://tonimalt-af.github.io/capy-mahjong/, commit `4f256f2`) and its code. Effort scale: S < ½ day, M ≈ 1–2 days, L > 2 days. Every bug listed below was reproduced on the live site, except where marked *(code review)*.

## Measurements
- **Lighthouse (mobile, 4x CPU throttle):**
  - Scores: Performance 96, Accessibility 93, Best practices 100, SEO 100.
  - Timings: LCP 1.5 s, TBT 220 ms, CLS 0.003.
  - Page weight: 177 KiB in total, with JS at 74 KB raw.
  - The only failing accessibility audit is `user-scalable=no`.
- **Third parties:** none. Every request goes to `tonimalt-af.github.io`. `npm audit` reports 0 vulnerabilities, and there are no runtime dependencies.
- **Low-end device (4x CPU, DPR 3, 144-tile board):** the level loads in about 1.0 s. Play runs at about 54 fps (p95 33 ms), a tap takes about 13 ms, and the home screen holds 60 fps.
- **Long session (75 games in a row):** the heap stays flat at about 2.7 MB, and the DOM node and listener counts stay flat. No leak.
- **Repo:** no secrets in the files or the git history. The Actions workflow has minimal permissions. The repo is public and has no licence file.
- **Simulation (40 plays per level, "random" and "smart" bots, real hint/shuffle budgets):**
  - Most levels are cleared 95–100% of the time.
  - Outliers: L13 (smart bot 63%), L26 (smart bot 55%, random 68%), L8 (random 80%).
  - Almost every loss comes from the shuffle bug (P0-1).

## P0: must fix
1. **Shuffle soft-lock** (M)
   - Repro: start level 8 (`?level=7`), seed 70859. Play these pairs: `[16,46],[31,62],[7,17],[39,51],[8,23],[22,63],[15,40],[0,24],[52,58],[38,53],[6,37],[1,25],[36,59],[35,57],[5,45],[4,44],[32,34],[14,43],[26,54],[33,42],[9,55],[13,47],[41,60],[18,48],[30,49],[12,56],[10,11],[3,29],[19,28],[20,27]`. That leaves 1 loose tile and a column of 3 stacked tiles. Then tap "Mélanger".
   - Result:
     - `reshuffle()` throws `could not build deal`.
     - Each tap silently uses up a shuffle, while the label stays "(3)".
     - The "Plus de paires" overlay has no way out (no Recommencer or Quitter).
     - A shuffle had also cleared the undo history, so once the undos are used up the player is stuck. The "Reprendre" button then reloads the same dead game.
   - In simulation this happened 54 times. Screenshot: `/tmp/audit/shuffle-softlock.png`.
   - Fix:
     - Catch the error.
     - Detect positions that no shuffle can fix, and show "Plus de coups possibles" with Annuler / Recommencer / Quitter.
     - Never use up a shuffle on a failed attempt, and always offer Recommencer/Quitter on the overlay.
     - Stop the timer while the overlay is up.
     - Add a solver check to the level seeds.
2. **A bad save means a permanent blank screen, and an unreadable save is silently erased** (S)
   - Repro A: `localStorage['capy-mahjong-v1']='{"stars":null}'` → blank page on every visit. `{"theme":"nope"}` does the same.
   - Repro B: an unreadable save (`{not json`) loads as a brand-new game, and the first setting change overwrites it, so all progress is lost.
   - Fix:
     - Check the type of every field when loading, and fall back to the default value per field.
     - Keep a `.bak` copy of the last good save.
     - Wrap the boot in a try/catch that shows a "Problème de sauvegarde" screen with Exporter / Réinitialiser.

## P1: high value
1. **Bad links crash the game** (S)
   - These links throw an error and the game doesn't start: `?level=abc`, `?level=-1`, `?mode=zen&seed=abc`, `?mode=zen&layout=constructor` (or `__proto__`), `?mode=endless&round=-3`.
   - Fix: clamp the numbers, and look layouts up with `Object.hasOwn`.
2. **Carrot farming and a too-generous start** (S)
   - `?mode=daily&day=2001-01-01` (any past date) counts as a make-up challenge. Three such links paid 235 carrots.
   - A brand-new player also sees 30 "missed" days, worth about 1,350 carrots on day one (20 per day, +25 for the guaranteed capydindon). That is 40% of the shop.
   - Fix: check `canReplay` before accepting a link, and only count days since the first time the game was played.
3. **Zen share links don't always give the same board** (S)
   - 5 to 11 links out of 60 (about 8–18%) give a different board, depending on difficulty. The fairness re-pick runs again on the receiving side, on the default layout for that seed rather than the layout in the link.
   - Fix: put the final seed in the link and skip the re-pick when the link has a seed.
4. **Content Security Policy and save hardening** (S)
   - The carrot count and outfit from localStorage go straight into the HTML: a save with `carrots:"<img onerror=…>"` runs code (checked).
   - localStorage is shared with every other `tonimalt-af.github.io/*` project, so another project could inject this.
   - Fix:
     - Add a meta CSP: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'; worker-src 'self'; object-src 'none'; base-uri 'self'; form-action 'none'`. The JSON-LD block is not affected.
     - Add a referrer-policy meta.
     - Force the right type on every save field (fix P0-2).
     - GitHub Pages can't set real HTTP headers, so frame-ancestors/HSTS are out of reach.
5. **Safari erases data after 7 days without a visit (ITP)** (M)
   - Players who haven't added the game to their home screen lose their streak and progress.
   - Fix: call `navigator.storage.persist()`, and add a "Code de sauvegarde" (export/import of a copy-paste text) in Réglages.
6. **Service worker** (S–M) *(code review)*
   - (a) The cleanup step deletes every cache on the shared origin, including other projects' caches. Filter on the `capy-` prefix.
   - (b) The page is served cache-first, so players get each update only on their second visit, and an update in the middle of a session can make old fonts 404.
   - Fix: network-first for the page itself with an offline fallback, plus a "Nouvelle version prête" toast that applies on the home screen. This isn't an install prompt.
7. **iOS audio** (S) *(code review, not tested on a device)*
   - The audio unlock only listens to `pointerdown`. Also listen to `touchend`/`click`.
   - After a call or Siri, iOS puts the audio in the `interrupted` state, and `ensure()` only resumes from `suspended`. Resume on the next tap.
8. **Difficulty now that the pair highlight is off by default** (S)
   - L13 and L26 are spikes: the smart bot wins only 63% and 55%, against about 100% for the levels around them. Pick new seeds with a solver.
   - Worlds 4–5 give only 1 hint on boards of 96–144 tiles. Suggestions: 2 hints in worlds 4–5, and maybe auto-hint on by default in Rivière.
   - The daily challenge (1 hint, 1 shuffle) averages 97% in simulation (worst 73%).
9. **Economy versus the one-month shop target** (M)
   - The shop totals 3,240 carrots.
   - A regular player (daily challenge + 2 levels a day + achievements) earns about 3,900 in 30 days, so the shop is empty by about day 24. A daily-only player empties it in about 31 days.
   - Once the shop is empty, carrots are worth nothing.
   - Add a monthly carrot sink: seasonal items, a "bouillotte" streak freeze (about 60 carrots), and tile sets per world.

## P2: nice to have
- **Accessibility:** remove `user-scalable=no` (S). Make tiles focusable for keyboard play (M).
- **Pause and keys:** stop the timer while the portrait "Tourne ton téléphone" screen is up (S). The `z` key undoes even while paused (S).
- **Deep links:** `?level=N` skips the locks and the tutorial for a new player. `?mode=endless&round=40` hands out the Marathon achievement and inflates the record (S).
- **French plurals:** "Il te manque 1 carottes", "Record Infini : 1 manches" (S).
- **CI:** pin the Actions to commit SHAs, add Dependabot, and give `pages`/`id-token: write` to the deploy job only (S).
- **Repo hygiene:** `previews/` is 104 MB (99 tracked files), and `.git` is 68 MB. Move them out (Git LFS or a separate branch) (S).
- **Licences:** `LICENSES.md` doesn't list the AI-generated `home-bg.webp` or the `og-image` built from it. Add them, along with the generator's terms (S).
- **Performance:** add `fetchpriority=high` or a preload for the home image and the 700-weight font. GitHub Pages caches for 10 minutes and that can't be changed; the service worker already covers it (S).
- **Shuffle and undo:** a shuffle clears the undo history; keeping it would be fairer (S).

## Progress
**Phase 1 — P0 + security (30 oct. 2026)**
- **Shuffle soft-lock:** `reshuffle()` returns `solvable` / `pair` / `dead`. It never throws and doesn't change the board on failure. A dead board (stacked tiles, or proven by exact search when 28 tiles or fewer remain) shows the "Tuiles coincées" card with Annuler / Recommencer / Quitter. No shuffle is spent, undo history is kept, and the clock stops on end cards. A new keyboard shortcut `s` shuffles.
- **Saves:** per-field validation with defaults (`sanitize`) and a backup key `.bak` holding the last good save. A corrupt save is kept in `.corrupt` and the backup is restored, with a toast. A failed write shows a warning and is never silent. A boot crash shows a recovery screen (Copier ma sauvegarde / Repartir de zéro / Recharger).
- **Deep links:** strict parsing (`src/deeplink.ts`). Invalid links go home with "Lien invalide". Locked levels open the map. Endless always starts at round 1. Daily replay is bounded. The URL is cleaned after use.
- **XSS:** save and URL text only ever reaches the page as escaped text or `textContent`. Run data is validated on load.
- **CSP:** a meta CSP is injected at build time, with `script-src 'self'` and no inline script. The e2e suite checks fonts, images, audio, a full game, and the service worker with zero CSP violations.
- **Namespacing:** caches are named `capy-mahjong-<hash>`. Only our own caches are deleted (including legacy `capy-<hash>`). The service worker ignores requests outside its scope. localStorage was already `capy-mahjong-v1*`.
- **Tests:** each audit repro is now a regression test (`tests/security.test.ts`, `tests/sw.test.ts`, `e2e/security.spec.ts`).

**Phase 2 — P1 + P2:** in progress.
